# Свадебное приглашение — Ахмед & Динара

Это полностью статический сайт. Для работы достаточно открыть `index.html`.
Для публикации позже можно использовать VPS, GitHub Pages, Netlify, Vercel или любой статический хостинг.

## Структура

```text
wedding_invitation_final/
├── index.html
├── css/
│   ├── variables.css
│   ├── reset.css
│   ├── animations.css
│   ├── style.css
│   └── responsive.css
├── js/
│   ├── content.js
│   └── app.js
├── google_apps_script.gs
└── README.md
```

## Где менять тексты, даты и адрес

Открывайте только:

```text
js/content.js
```

В этом файле находятся:

- имена;
- дата и время свадьбы;
- текст приглашения;
- программа дня;
- адрес;
- ссылка «Построить маршрут»;
- координаты карты;
- ссылка Google Apps Script;
- сообщения формы.

## Координаты карты

В `js/content.js` замените:

```javascript
latitude: 53.000000,
longitude: 45.000000,
```

на реальные координаты площадки.

## Подключение Google Sheets

1. Создайте Google Таблицу.
2. Откройте `Расширения → Apps Script`.
3. Удалите стандартный код.
4. Вставьте код из файла `google_apps_script.gs`.
5. Сохраните проект.
6. Выберите `Развернуть → Новое развертывание`.
7. Тип: `Веб-приложение`.
8. Выполнять от имени: `Я`.
9. Доступ: `Все`.
10. Скопируйте URL, заканчивающийся на `/exec`.
11. Вставьте его в `js/content.js`:

```javascript
googleScriptUrl: "https://script.google.com/macros/s/.../exec"
```

## Персональные ссылки

Можно передать имя гостя через параметр `guest`:

```text
index.html?guest=Ильдар
```

После публикации пример будет выглядеть так:

```text
https://ваш-домен.ru/?guest=Ильдар
```

Имя автоматически:

- появится в приглашении;
- заполнится в анкете;
- сохранится в Google Sheets.

Для имён с пробелами браузер обычно сам кодирует ссылку. Пример:

```text
https://ваш-домен.ru/?guest=Ильдар%20и%20Алина
```

## Локальный запуск

Самый простой вариант:

- распакуйте архив;
- откройте `index.html`.

Для стабильного тестирования отправки формы используйте VS Code и расширение Live Server.
